Introduction to DSA

Data Structures and Algorithms (DSA) are fundamental concepts in computer science. They help in organizing data efficiently and solving problems in optimal ways.

Mastering DSA is essential for cracking technical interviews and building efficient applications.

Arrays

Arrays store elements in contiguous memory locations. They allow fast access using index.

Key Operations

  • Access → O(1)
  • Insertion → O(n)
  • Deletion → O(n)
```

let arr = [10,20,30,40];
console.log(arr[2]); // 30
```

Arrays are widely used in problems involving indexing, sliding window, and prefix sums.

Strings

Strings are sequences of characters. They are widely used in pattern matching problems. 

```

let str = "hello";
console.log(str.length);
```

Linked List

A linked list is a collection of nodes where each node points to the next node. 

```

class Node {
constructor(data){
this.data = data;
this.next = null;
}
}
```

Types: Singly, Doubly, Circular Linked List

Stack

Stack follows LIFO (Last In First Out). 

```

let stack = [];
stack.push(10);
stack.pop();
```

Queue

Queue follows FIFO (First In First Out). 

```

let queue = [];
queue.push(10);
queue.shift();
```

Recursion

Recursion is a function calling itself to solve smaller subproblems. 

```

function fact(n){
if(n==0) return 1;
return n * fact(n-1);
}
```

Trees

Trees are hierarchical structures with a root node. 

```

class TreeNode {
constructor(val){
this.val = val;
this.left = null;
this.right = null;
}
}
```

Graphs

Graphs consist of nodes and edges. Used in networking, maps, etc. 

```

let graph = {
A: ["B","C"],
B: ["A","D"],
C: ["A"],
D: ["B"]
};
```

Dynamic Programming

DP solves problems by storing results of subproblems. 

```

function fib(n){
let dp=[0,1];
for(let i=2;i<=n;i++){
dp[i]=dp[i-1]+dp[i-2];
}
return dp[n];
}
```
