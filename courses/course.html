🚀 Introduction to DSA

Data Structures and Algorithms (DSA) form the backbone of computer science and software engineering. A data structure is a way of organizing and storing data so it can be accessed and modified efficiently. An algorithm is a step-by-step procedure to solve a problem.

Mastering DSA is the single most important skill for cracking technical interviews at top companies like Google, Amazon, and Microsoft, and for writing efficient, scalable software.

Why Learn DSA?

  • Write code that runs faster and uses less memory
  • Solve complex problems by breaking them into smaller pieces
  • Crack coding interviews at top tech companies
  • Understand how real-world systems are built

📦 Arrays

An array is a collection of elements stored at contiguous memory locations. It is the simplest and most widely used data structure. Elements are accessed using an index starting at 0.

Key Fact: Arrays provide O(1) access time because the address of any element can be computed directly: base_address + index × element_size.

Declaring Arrays

// Fixed array
let arr = [10, 20, 30, 40, 50];

// Access element
console.log(arr[2]); // → 30

// Modify element
arr[1] = 99;

// Length
console.log(arr.length); // → 5

Common Operations

OperationTimeNotes
AccessO(1)Direct index
SearchO(n)Linear scan
Insert at endO(1)Amortized (dynamic arrays)
Insert at middleO(n)Shift elements right
DeleteO(n)Shift elements left

Two Pointer Technique

A powerful pattern for problems on arrays — use two indices moving toward each other.

// Check if array is palindrome
function isPalindrome(arr) {
  let left = 0, right = arr.length - 1;
  while (left < right) {
    if (arr[left] !== arr[right]) return false;
    left++;
    right--;
  }
  return true;
}

Sliding Window

Used to find subarrays of a fixed or variable size efficiently in O(n).

// Maximum sum of k consecutive elements
function maxSumWindow(arr, k) {
  let sum = 0;
  for (let i = 0; i < k; i++) sum += arr[i];
  let maxSum = sum;
  for (let i = k; i < arr.length; i++) {
    sum += arr[i] - arr[i - k];
    maxSum = Math.max(maxSum, sum);
  }
  return maxSum;
}

🔤 Strings

A string is a sequence of characters. In JavaScript, strings are immutable — you cannot change individual characters directly.

Common String Methods

let s = "hello world";

s.length;          // 11
s.toUpperCase();  // "HELLO WORLD"
s.split(" ");     // ["hello", "world"]
s.includes("world"); // true
s.slice(0, 5);   // "hello"
s.replace("world", "JS"); // "hello JS"

Reverse a String

function reverseString(s) {
  return s.split("").reverse().join("");
}

Check Anagram

Two strings are anagrams if they contain the same characters in any order.

function isAnagram(a, b) {
  if (a.length !== b.length) return false;
  return a.split("").sort().join("") === b.split("").sort().join("");
}

🔗 Linked List

A linked list is a linear data structure where elements (called nodes) are stored in non-contiguous memory locations. Each node contains data and a pointer to the next node.

Types

  • Singly Linked List – each node points to the next
  • Doubly Linked List – each node points to both next and previous
  • Circular Linked List – tail points back to head

Node & Basic Operations

class Node {
  constructor(data) {
    this.data = data;
    this.next = null;
  }
}

class LinkedList {
  constructor() { this.head = null; }

  append(data) {
    let node = new Node(data);
    if (!this.head) { this.head = node; return; }
    let curr = this.head;
    while (curr.next) curr = curr.next;
    curr.next = node;
  }

  print() {
    let curr = this.head;
    while (curr) { console.log(curr.data); curr = curr.next; }
  }
}
OperationSinglyDoubly
AccessO(n)O(n)
Insert at headO(1)O(1)
Insert at tailO(n)O(1)*
DeleteO(n)O(n)

📚 Stack

A stack is a LIFO (Last In, First Out) data structure. Think of a pile of plates — you can only add or remove from the top.

Operations

  • push() – add element to top
  • pop() – remove element from top
  • peek() – view top element without removing
  • isEmpty() – check if stack is empty
class Stack {
  constructor() { this.items = []; }
  push(el) { this.items.push(el); }
  pop()    { return this.items.pop(); }
  peek()   { return this.items[this.items.length - 1]; }
  isEmpty(){ return this.items.length === 0; }
}

// Real use: Balanced parentheses check
function isBalanced(s) {
  let stack = [];
  const map = {')':'(', '}':'{', ']':'['};
  for (let ch of s) {
    if ("({[".includes(ch)) stack.push(ch);
    else if (stack.pop() !== map[ch]) return false;
  }
  return stack.length === 0;
}
Real-world uses: Undo/Redo in editors, function call stack, browser back button, expression evaluation.

🚶 Queue

A queue is a FIFO (First In, First Out) data structure. Think of a line at a ticket counter — the first person to join is the first to be served.

Operations

class Queue {
  constructor() { this.items = []; }
  enqueue(el) { this.items.push(el); }
  dequeue()   { return this.items.shift(); }
  front()     { return this.items[0]; }
  isEmpty()   { return this.items.length === 0; }
}

// BFS uses a Queue
function bfs(graph, start) {
  let visited = new Set([start]);
  let queue = [start];
  while (queue.length) {
    let node = queue.shift();
    console.log(node);
    for (let neighbor of graph[node]) {
      if (!visited.has(neighbor)) {
        visited.add(neighbor);
        queue.push(neighbor);
      }
    }
  }
}

Types of Queues

  • Simple Queue – basic FIFO
  • Circular Queue – rear wraps around to front
  • Priority Queue – elements have priority (like a min-heap)
  • Deque – insertion/deletion at both ends

🔄 Recursion

Recursion is a technique where a function calls itself to solve a smaller version of the same problem. Every recursive function needs a base case (to stop) and a recursive case (to reduce the problem).

// Factorial: n! = n × (n-1)!
function factorial(n) {
  if (n === 0) return 1; // base case
  return n * factorial(n - 1); // recursive case
}

// Fibonacci
function fib(n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}

// Sum of array recursively
function sumArray(arr, i = 0) {
  if (i === arr.length) return 0;
  return arr[i] + sumArray(arr, i + 1);
}
Tip: Always identify the base case first. Without it, recursion causes a stack overflow.

Call Stack Visualization

        → 2 × factorial(1)
              → 1 × factorial(0)
                    → returns 1
              → returns 1
        → returns 2
  → returns 6

🔍 Searching Algorithms

Linear Search

Checks each element one by one. Works on unsorted arrays. Time: O(n).

function linearSearch(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === target) return i;
  }
  return -1;
}

Binary Search

Works only on sorted arrays. Repeatedly halves the search range. Time: O(log n).

function binarySearch(arr, target) {
  let left = 0, right = arr.length - 1;
  while (left <= right) {
    let mid = Math.floor((left + right) / 2);
    if (arr[mid] === target) return mid;
    else if (arr[mid] < target) left = mid + 1;
    else right = mid - 1;
  }
  return -1;
}

// Example
binarySearch([2,5,8,12,16], 12); // → 3
AlgorithmBestAverageWorstRequirement
Linear SearchO(1)O(n)O(n)None
Binary SearchO(1)O(log n)O(log n)Sorted array

↕️ Sorting Algorithms

Bubble Sort

Repeatedly swaps adjacent elements if they are in the wrong order. Simple but slow — O(n²).

function bubbleSort(arr) {
  let n = arr.length;
  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n - i - 1; j++) {
      if (arr[j] > arr[j+1]) {
        [arr[j], arr[j+1]] = [arr[j+1], arr[j]];
      }
    }
  }
  return arr;
}

Selection Sort

Finds the minimum element and places it at the correct position each pass.

function selectionSort(arr) {
  let n = arr.length;
  for (let i = 0; i < n; i++) {
    let minIdx = i;
    for (let j = i + 1; j < n; j++) {
      if (arr[j] < arr[minIdx]) minIdx = j;
    }
    [arr[i], arr[minIdx]] = [arr[minIdx], arr[i]];
  }
  return arr;
}

Merge Sort

Divide and conquer — splits array in half, sorts each half, then merges. O(n log n).

function mergeSort(arr) {
  if (arr.length <= 1) return arr;
  let mid = Math.floor(arr.length / 2);
  let left  = mergeSort(arr.slice(0, mid));
  let right = mergeSort(arr.slice(mid));
  return merge(left, right);
}

function merge(l, r) {
  let res = [], i = 0, j = 0;
  while (i < l.length && j < r.length) {
    res.push(l[i] < r[j] ? l[i++] : r[j++]);
  }
  return [...res, ...l.slice(i), ...r.slice(j)];
}

🌳 Trees

A tree is a hierarchical data structure with a root node, and each node has zero or more children. Trees have no cycles.

Binary Tree

Each node has at most two children: left and right.

class TreeNode {
  constructor(val) {
    this.val = val;
    this.left = null;
    this.right = null;
  }
}

Tree Traversals

// Inorder: Left → Root → Right (gives sorted order for BST)
function inorder(node) {
  if (!node) return;
  inorder(node.left);
  console.log(node.val);
  inorder(node.right);
}

// Preorder: Root → Left → Right
function preorder(node) {
  if (!node) return;
  console.log(node.val);
  preorder(node.left);
  preorder(node.right);
}

// Postorder: Left → Right → Root
function postorder(node) {
  if (!node) return;
  postorder(node.left);
  postorder(node.right);
  console.log(node.val);
}

Binary Search Tree (BST)

Left subtree ≤ node ≤ Right subtree. Search, insert, delete all O(log n) on average.

Key Terms: Height, Depth, Leaf node, Root, Balanced tree, Full binary tree, Complete binary tree.

🕸️ Graphs

A graph is a collection of vertices (nodes) connected by edges. Graphs can be directed or undirected, weighted or unweighted.

Representation

// Adjacency List (most common)
const graph = {
  A: ["B", "C"],
  B: ["A", "D"],
  C: ["A", "E"],
  D: ["B"],
  E: ["C"]
};

Depth First Search (DFS)

function dfs(graph, node, visited = new Set()) {
  if (visited.has(node)) return;
  visited.add(node);
  console.log(node);
  for (let neighbor of graph[node]) {
    dfs(graph, neighbor, visited);
  }
}

Breadth First Search (BFS)

function bfs(graph, start) {
  let visited = new Set([start]);
  let queue = [start];
  while (queue.length) {
    let node = queue.shift();
    console.log(node);
    for (let n of graph[node]) {
      if (!visited.has(n)) { visited.add(n); queue.push(n); }
    }
  }
}

💡 Dynamic Programming

Dynamic Programming (DP) solves complex problems by breaking them into overlapping subproblems and storing results to avoid recomputation. Two approaches: Top-down (Memoization) and Bottom-up (Tabulation).

Fibonacci – Memoization

function fib(n, memo = {}) {
  if (n in memo) return memo[n];
  if (n <= 1) return n;
  memo[n] = fib(n-1, memo) + fib(n-2, memo);
  return memo[n];
}

Fibonacci – Tabulation

function fib(n) {
  let dp = [0, 1];
  for (let i = 2; i <= n; i++) {
    dp[i] = dp[i-1] + dp[i-2];
  }
  return dp[n];
}

0/1 Knapsack Problem

function knapsack(weights, values, W) {
  let n = weights.length;
  let dp = Array.from({length: n+1}, () => new Array(W+1).fill(0));
  for (let i = 1; i <= n; i++) {
    for (let w = 0; w <= W; w++) {
      dp[i][w] = dp[i-1][w];
      if (weights[i-1] <= w) {
        dp[i][w] = Math.max(dp[i][w], dp[i-1][w - weights[i-1]] + values[i-1]);
      }
    }
  }
  return dp[n][W];
}
DP Checklist: Does the problem have overlapping subproblems? Does it have optimal substructure? If yes to both → DP is likely the right approach.

📦 OOP Concepts

Java is built around four pillars of Object-Oriented Programming.

1. Encapsulation

Wrapping data and methods into a class, hiding internal details using private/public.

class Student {
  private String name;
  private int age;

  public String getName() { return name; }
  public void setName(String n) { this.name = n; }
}

2. Inheritance

A child class inherits properties and methods from a parent class using extends.

class Animal {
  void sound() { System.out.println("Some sound"); }
}

class Dog extends Animal {
  void sound() { System.out.println("Woof!"); }
}

3. Polymorphism

Same method name behaves differently. Runtime polymorphism via method overriding.

Animal a = new Dog();
a.sound(); // Output: Woof! (dynamic dispatch)

4. Abstraction

Hiding implementation details. Achieved via abstract classes and interfaces.

interface Shape {
  double area();
}

class Circle implements Shape {
  double r;
  Circle(double r) { this.r = r; }
  public double area() { return Math.PI * r * r; }
}

⚠️ Exception Handling

📱 Responsive Design

Responsive design makes websites look good on all screen sizes using media queries.

/* Default: Desktop */
.container { width: 1100px; }

/* Tablet */
@media (max-width: 768px) {
  .container { width: 100%; padding: 0 20px; }
  .grid { grid-template-columns: 1fr 1fr; }
}

/* Mobile */
@media (max-width: 480px) {
  .grid { grid-template-columns: 1fr; }
  nav { display: none; }
  .mobile-menu { display: block; }
}

Mobile-First Approach

Write CSS for mobile first, then add media queries for larger screens using min-width.

/* Mobile first */

Variables & Functions

let name = "Alice";     // block-scoped
const PI = 3.14;       // constant
var old = "avoid";     // function-scoped (avoid)

// Function declaration
function greet(name) {
  return `Hello, ${name}!`;
}

// Arrow function
const add = (a, b) => a + b;

// Array methods
const nums = [1,2,3,4];
nums.map(x => x * 2);      // [2,4,6,8]
nums.filter(x => x > 2);   // [3,4]
nums.reduce((s,x) => s+x, 0); // 10

🌲 DOM Manipulation

The DOM (Document Object Model) represents the HTML page as a tree. JavaScript can read and modify it dynamically.

// Selecting elements
const el = document.getElementById("myId");
const els = document.querySelectorAll(".card");

// Modifying content
el.textContent = "New text";
el.innerHTML = "<strong>Bold</strong>";

// Modifying styles
el.style.color = "red";
el.classList.add("active");
el.classList.toggle("hidden");

// Creating and appending elements
const div = document.createElement("div");
div.textContent = "New card";
document.body.appendChild(div);

🖱️ Events

// Click event
document.getElementById("btn")
  .addEventListener("click", () => {
    alert("Clicked!");
  });

// Input event
document.getElementById("search")
  .addEventListener("input", (e) => {
    console.log(e.target.value);
  });

// Keyboard event
document.addEventListener("keydown", (e) => {
  if (e.key === "Escape") closeModal();
});

// Event delegation (efficient for many elements)
document.getElementById("list")
  .addEventListener("click", (e) => {
    if (e.target.tagName === "LI") {
      e.target.classList.toggle("done");
    }
  });

🔌 Fetch API & Async JS

The Fetch API lets you make HTTP requests from JavaScript to get data from servers.

Promises & Async/Await

// Fetch with async/await
async function getData() {
  try {
    const res = await fetch("https://api.example.com/data");
    const json = await res.json();
    console.log(json);
  } catch (err) {
    console.error("Error:", err);
  }
}

// POST request
async function postData(url, data) {
  const res = await fetch(url, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(data)
  });
  return res.json();
}
Key Concepts: Promises represent future values. async/await is syntax sugar over Promises that makes asynchronous code look synchronous and easier to read.
